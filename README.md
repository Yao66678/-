# 高速实时音频频谱分析系统

基于 Xilinx Artix-7 FPGA 的高速实时音频频谱分析与可视化系统。将**采样、加窗、FFT 变换、后处理、显示渲染**五个环节全部硬件化，全过程不经 CPU 与帧存，实现毫秒级端到端延迟的频谱实时显示。

---

## 硬件平台

| 项目 | 参数 |
| --- | --- |
| 开发板 | ACX720 |
| 主控芯片 | Xilinx Artix-7 `XC7A35T-2FGG484` |
| 音频编解码 | ES8388（I²C 配置 + I²S 数据） |
| 显示 | 800×480 TFT LCD（RGB565） |
| 板载晶振 | 50 MHz |
| 开发工具 | Vivado 2025.2 |

## 系统架构

```
 麦克风 ─► ES8388 ─I2S─► 加窗 ─► 1024 点 FFT ─► 求模/校正 ─► 频谱渲染 ─► TFT
             ▲                                                              │
             └──────────── I2C 配置寄存器 ◄─────────────────────────────────┘
                        （全链路硬件流水，同一时钟节拍推进）
```

系统摒弃「取指—译码—执行」的串行指令流，把五个处理环节拆分为独立硬件模块，在统一节拍下流水推进，因此延迟只取决于流水线深度，而非软件调度。

## 模块说明

| 文件 | 功能 |
| --- | --- |
| `top.v` | 顶层，例化各子模块并驱动 TFT 时序 |
| `fft_1024.xci` | 1024 点 FFT IP，基-2² 单路径延迟反馈（SDF）架构，10 级蝶形流水线 |
| `hanning_window.v` | 汉宁窗加窗，抑制频谱泄漏 |
| `i2s_rx.v` | I²S 音频数据接收 |
| `i2c_es8388_cfg.v` | ES8388 编解码器寄存器配置 |
| `spectrum_draw.v` | 频谱柱状渲染，由幅值直接生成 RGB 像素 |
| `fft_8.v` | 辅助运算模块 |
| `top.xdc` | 引脚与时序约束 |

## 关键技术

1. **全流水线 FFT**：基-2² SDF 架构，每级仅一条数据通路 + 一个反馈延迟单元，用反馈移位寄存器暂存配对样点（第 1 级隔 512 点递减至第 10 级隔 1 点），省去地址发生器与双端口 RAM，1024 点复数 FFT 单帧运算约 **6.1 μs**。
2. **完整幅值校正链**：加窗 → 归一化 → 对数压缩 → 频带聚合 → 峰值保持，逐级消除误差源；汉宁窗系数乘 2 抵消相干增益损失。
3. **硬件实时渲染**：以频谱能量为唯一输入直接生成 RGB 像素流，几何层查表定位、色彩层分段线性 HSV→RGB、动态层峰值保持与逐帧衰减，全程不经帧存与 CPU。

## 快速开始

1. 安装 **Vivado 2025.2**（含 Artix-7 器件库）
2. 双击 `cc.xpr` 打开工程
3. 由于 IP 未随仓库提交生成产物，首次打开需在 Sources 面板右键 `fft_1024` → **Generate Output Products**
4. 点击 **Generate Bitstream**
5. 连接 ACX720 开发板，**Open Hardware Manager** → Program Device

> ⚠️ 首次综合前需登录 Xilinx 账号（生成 FFT IP 需要 license 校验），这是 Vivado IP 流程的常规要求。

## 工程现状

当前 `top.v` 处于**内部信号自测模式**：外部 I²C/I²S 引脚被屏蔽（`assign i2s_bclk = 0` 等），音频源由片内锯齿波发生器 `phase_acc` 模拟，用于在无麦克风输入时验证 FFT 与显示链路。

`i2s_rx.v`、`i2c_es8388_cfg.v`、`hanning_window.v` 已编写完成但尚未在顶层例化。切换为真实麦克风输入需在 `top.v` 中恢复 I²S 接收与 ES8388 配置模块的例化。
